# Recording the sounds

Until you record a sound, the app uses the tablet's built-in voice to guess at it
("shh", "buh"). The guesses are rough, so your recordings make a big difference,
especially for the six new Unit 3 sounds at the top of the list.

## How to record

1. Use any voice recorder (a phone's voice recorder app is fine). Record in a quiet room.
2. Say **only the sound**, short and clean: /sh/, not "shuh" and not the letter name.
   For stop sounds (b, c, d, g, k, p, t) keep it as clipped as you can: "b", not "buh".
3. Trim the silence before and after, so each file is about 1 second.
4. Name each file exactly as in the table (lowercase). `.mp3` or `.m4a` both work,
   so a phone's `.m4a` recording is fine as it is: `sh.m4a`.
5. Put the files in the `audio/sounds` folder.

The parent screen (hold ⚙️ on the home screen) shows which sounds are recorded
(green) and which still use the robot voice. Tap any of them to hear it.

You don't have to do them all at once. Start with the Unit 3 sounds.
