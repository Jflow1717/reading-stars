# The sounds

The app comes with a sound file for every letter, digraph and qu, in `audio/sounds/`
(like `th.m4a`). Each one is the sound itself ("thhh"), never the letter names ("T, H").

They were made on a Mac by giving Apple's speech engine the exact speech sound as a
phonetic symbol, then checked by measuring each file:

- no vowel at all in hissing sounds like s, sh, th and f, which rules out "ess" and "eff"
- b, d and g clipped short, not "bee", "dee", "gee"
- each short vowel matching its own sound

They are still a computer voice. Trick Words also has a file for each letter's name in
`audio/names/` ("aitch", "ay", "ess").

## Using your own voice instead (optional)

1. Use any voice recorder (a phone's voice recorder app is fine). Record in a quiet room.
2. Say **only the sound**, short and clean: /sh/, not "shuh" and not the letter name.
   For stop sounds (b, c, d, g, k, p, t) keep it as clipped as you can: "b", not "buh".
3. Trim the silence before and after, so each file is about 1 second.
4. Either save it as an `.mp3` with the name in the table (`th.mp3`), which plays
   instead of the app's `th.m4a`, or replace the `.m4a` file with your own `.m4a` of the same name.
5. Put the files in the `audio/sounds` folder and publish the change.

The grown-up screen (hold ⚙️ on the home screen) lists every sound. Tap one to hear it.
